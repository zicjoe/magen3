# Support

## Product and Setup Questions

Use GitHub Discussions when enabled, or open a GitHub issue using the question template. Include your environment, exact command, expected result, observed result, and sanitized logs.

## Bugs

Use the bug-report template and provide reproducible steps. Do not include secrets or wallet private keys.

## Security Issues

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).

## Buildathon Verification

For judge-facing setup and testing, use the README and the current files under `docs/`. Archived implementation notes under `docs/archive/` are historical and are not the source of truth.
